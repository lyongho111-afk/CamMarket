캠퍼스 리마켓 — 추가 수정 완료 (2026-11-05)
============================================================
기준: 사용자가 제공한 학교분리·관리자CRUD 최종본.
이 문서는 이번 추가 수정의 최신 상태이며, 기존 안내는 이전 작업 이력입니다.

1. 거래 약속 알림 — 판매자와 구매자 모두에게
------------------------------------------------------------
- 거래 약속을 생성하면 판매자·구매자 각각에게 별도 앱 알림을 저장합니다.
- 제목을 판매 거래 약속 / 구매 거래 약속으로 구분합니다.
- 같은 상품·장소·시간·약속 가격을 양쪽이 확인할 수 있습니다.
- 회원별 이메일·전화번호·수신 여부 설정으로 외부 발송을 처리합니다.
- 한 사람의 수신 거부나 읽음 처리가 상대방 알림을 바꾸지 않습니다.
- 다른 회원의 알림을 읽음 처리하거나 재발송할 수 없습니다.
- 동일 거래·동일 수신자 중복 알림을 DB에서 방지합니다.
- 기존 알림·외부 발송 상태를 보존하는 자동 추가 마이그레이션을 넣었습니다.
- 이전 거래에 구매자 알림을 소급 발송하지 않습니다. 새 약속부터 적용됩니다.
- 약속 시간 직전의 예약 알림, 약속 변경·취소 알림은 이번에 추가하지 않았습니다.

2. 학교 분리·관리자 CRUD 유지
------------------------------------------------------------
- 인하대·인천대·청운대의 학교별 분리, 같은 학번 구분을 유지했습니다.
- 인천대·청운대 거래에서도 판매자와 구매자 알림을 확인하는 검사를 추가했습니다.
- 학교·업종 관리, 이미지, 내 정보·비밀번호 변경 등 제공본의 기능을 유지했습니다.
- TradeService, StudentMemberLink, CampusScope 등 최신 학교별 권한 연결을 이전 소스로 덮어쓰지 않았습니다.

3. 외부 서비스 확인 범위
------------------------------------------------------------
- 네이버 SMTP: 기존 비공개 설정으로 실제 서버 로그인 인증 통과.
- 솔라피: 기존 비공개 키로 조회 인증 200 확인. 이번 추가 작업에서 문자 발송·유료 충전 없음.
- 양쪽의 서로 다른 이메일·전화번호로 발송하는 코드는 모의 공급자와 로컬 메일로 검증했습니다.
- 과거 이메일·문자 실제 수신 기록은 유지하지만, 이번에 양쪽 실제 기기 수신을 새로 확인한 것으로 표시하지 않습니다.
- 카카오 알림톡: 비즈니스 채널 인증 및 양식 승인이 없어 미연결입니다.
- 발신 비밀번호, API 비밀키, 연락처가 포함된 실제 DB는 이 ZIP에 없습니다.
